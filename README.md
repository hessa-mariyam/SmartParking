# Smart Parking System

A C++ application for managing vehicle records and optimizing parking revenue.
Team Members : Gouri Nanda K G


## Features

- Add vehicle details
- Search vehicles using hashing
- Display registered vehicles
- Sort by arrival time
- Sort by parking duration
- Optimize revenue using dynamic programming

## Algorithms Used

- Hashing: Vehicle registration search
- Sorting: Arrival time and duration
- Dynamic Programming: 0/1 Knapsack
